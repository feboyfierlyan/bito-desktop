# Bito v0.6.0 — workspace & companion preview

Rilis preview untuk pengujian terbatas. Belum merupakan rilis produksi bertanda tangan dan bukan jaminan bebas bug.

## Yang berubah

- Workspace berbasis Astryx: navigasi berlabel, proyek dan kelompok tugas yang dapat diedit, penambahan tugas dengan tanggal, serta kalender/progres di panel samping.
- Perbaikan composer produksi: textarea mempertahankan lebar penuh meskipun urutan stylesheet berubah, sehingga placeholder tidak tersusun vertikal.
- Detail proyek kini dapat digulir sampai tugas terakhir dan panel ringkasan; pembungkus konten mengikuti tinggi jendela, termasuk proyek yang diarsipkan.
- Chat lebih ringkas, pilihan proyek sebagai overlay, preview lampiran, dan draft file yang baru diproses setelah Kirim.
- Tanya area layar sekali pakai, panduan layar, pencarian dengan sumber, serta sinkronisasi rencana yang disetujui ke Google Calendar.
- Bito berukuran default 180px; perpindahan dari onboarding ke desktop dan pill menggunakan transisi bentuk/ukuran. Buffer animasi dipertahankan selama handoff untuk mengurangi stutter.
- Penyimpanan menangani disk penuh tanpa uncaught exception; data yang belum tersimpan diberi status dan dapat dicoba ulang.

## Keamanan dan verifikasi

- Chat biasa tidak mengizinkan model memicu tangkapan layar atau mengakses metadata aplikasi aktif. Tool layar tak terduga ditolak sebelum eksekusi lokal.
- Lampiran tidak menerima path sembarang melalui perintah renderer. File berasal dari dialog OS atau File drop asli, dibaca dengan batas ukuran dan pemeriksaan regular file.
- Fungsi administratif database tidak dapat dieksekusi role anonim/authenticated. Tes PostgreSQL berjalan pada CI, termasuk RLS, isolasi pengguna, lease dan pencabutan akses.
- 389 tes lokal lolos tanpa skip; typecheck frontend/backend dan build lolos. Audit npm termasuk dependensi build: 0 kerentanan yang diketahui pada 5 November 2026.
- Integrasi live memakai data sintetis: sesi tersimpan tervalidasi, AI chat, analisis gambar lampiran, bantuan layar, dan Calendar create/read/delete. Event tes telah dihapus. Tidak mengunggah desktop atau dokumen pribadi.

## Batasan preview

- macOS memakai tanda tangan **ad-hoc**, belum Developer ID/notarization. Windows belum memakai sertifikat penerbit. Peringatan OS mungkin muncul.
- Login baru melalui consent Google dan kebijakan OAuth untuk seluruh pengguna belum diverifikasi pada installer di setiap platform. Uji live memakai akun yang sudah terhubung; akses backend tetap mengikuti daftar akun demo yang diizinkan.
- Interaksi native pada Windows/Intel belum diuji langsung pada mesin fisik. Build lintas platform dan tes CI tidak menggantikan pengujian tersebut.
- Calendar satu arah: Bito → Google Calendar; sinkronisasi berjalan saat Bito terbuka. Akun OAuth Testing mungkin perlu terdaftar sebagai test user.
- Penggunaan AI/screen memerlukan koneksi jaringan dan izin OS yang sesuai. Penandatanganan, notarization, uji installer/upgrade lintas platform, dan onboarding OAuth pengguna baru masih menjadi syarat sebelum promosi ke stable production.

## Unduhan

Mac Apple Silicon dan Intel: DMG serta ZIP. Windows x64: installer EXE. Cocokkan checksum dengan `SHA256SUMS.txt` yang disertakan dalam release.
