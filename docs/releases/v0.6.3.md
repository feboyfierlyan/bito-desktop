# Bito v0.6.3 — workspace lebih konsisten

Pembaruan Bito untuk macOS dan Windows dengan workspace yang lebih ringan dan perbaikan interaksi desktop.

- **Tugas** menggabungkan Hari ini dan Semua dalam satu halaman. Ringkasan menampilkan tugas yang perlu perhatian dan progres per proyek.
- **Jadwal, Proyek, dan Arsip** memakai tata letak yang selaras. Detail tugas terbuka di kolom kanan. Arsip dapat dilihat dan dipulihkan dari workspace.
- **Penyuntingan dan sesi kerja** mendapat perbaikan untuk menjaga draf, menyimpan perubahan tugas dan tanggal, serta melanjutkan pekerjaan.
- **Interaksi desktop** memakai area hover sesuai bentuk karakter dan jalur dari kaki Bito ke kontrol. Pembaruan ini juga memperbaiki alur onboarding dan bantuan layar.

GitHub Actions membangun installer dari tag rilis dan memeriksa tanda tangan ad-hoc paket Mac. `BUILD-INFO.txt` mencatat commit sumber dan `SHA256SUMS.txt` berisi checksum installer.

Pilih DMG atau ZIP sesuai arsitektur Mac, atau installer EXE untuk Windows x64. Keluar dari Bito sebelum memasang versi baru. Riwayat dan proyek tetap ada selama data aplikasi dipertahankan.

Paket Mac memakai tanda tangan ad-hoc. Windows belum memakai sertifikat penerbit. Instalasi, upgrade, dan interaksi native di Windows dan Mac Intel masih memerlukan uji langsung. Akses layanan AI mengikuti izin akun demo.
