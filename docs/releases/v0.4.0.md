# Bito v0.4.0 — Onboarding polish checkpoint

Checkpoint setelah revisi onboarding percakapan dan pupil tracking. Versi ini menjadi titik lanjut untuk sesi revisi berikutnya.

## Perubahan

- Jawaban user muncul dahulu, Bito membalas setelah 340 ms, lalu petunjuk berikutnya muncul setelah balasan selesai.
- Percakapan maju/mundur bergerak dari bawah; pesan tujuan melakukan reveal ulang saat kembali.
- Navigasi membatalkan balasan tertunda agar pesan tidak masuk ke langkah yang salah. Input tetap bisa digunakan selama reveal.
- Pilihan Hangat/Tenang/Langsung mendapat respons Bito sebelum instruksi seret.
- Mata mengikuti cursor pada langkah 1–2, lalu kembali netral pada langkah 3 dan ketika kehilangan fokus.
- Bubble morph tanpa rotasi, tooltip, atau cursor klik. Klik Bito pada langkah 1–2 tetap wave.
- Gesture onboarding memakai satu pemilik input. Tombol pindah manual dan outline karakter dihapus.
- Mode revisi cepat tersedia lewat `Revisi Bito.command` / `npm run dev` dengan profil uji terpisah.

## Download

- **Mac Apple Silicon (M1/M2/M3 dan lebih baru):** `Bito-0.4.0-macOS-arm64.dmg` atau `.zip`.
- **Mac Intel:** `Bito-0.4.0-macOS-x64.dmg` atau `.zip`.
- **Windows 64-bit:** `Bito-0.4.0-Windows-x64-Setup.exe`.
- `SHA256SUMS.txt` untuk memeriksa unduhan, `BUILD-INFO.txt` untuk commit dan asal build.

macOS: buka DMG, pindahkan Bito ke Applications. Windows: jalankan installer EXE. Tutup versi Bito yang sedang berjalan sebelum menggantinya. Profil aplikasi tersimpan di folder data OS; mode revisi memakai profil terpisah.

## Validasi dan batas

Tes otomatis dan packaging dijalankan di runner macOS dan Windows sebelum release dipublikasikan. Alur onboarding diperiksa langsung pada macOS; pengujian visual/gesture Windows dan Mac Intel masih perlu dilakukan pada perangkat tersebut. Ini prototype kuliah yang belum ditandatangani/notariskan. AI memerlukan API key pengguna sendiri; onboarding, karakter, fokus, tugas, dan pengingat dapat dicoba tanpa key. Tidak ada auto-update atau kontrol desktop bebas.
