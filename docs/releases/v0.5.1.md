# Bito v0.5.1 — Teman kecil, siap menemani

Semua fitur companion v0.5.0, dengan perbaikan paket Mac dan pemeriksaan distribusi tambahan.

## Yang diperbaiki

- Paket Mac Apple Silicon dan Intel sekarang diberi tanda tangan ad-hoc setelah aplikasi selesai disusun, sehingga metadata dan resource aplikasinya konsisten.
- Sebelum publikasi, build mengekstrak ZIP kedua arsitektur lalu memverifikasi aplikasi beserta komponen di dalamnya. Paket yang gagal pemeriksaan tidak diterbitkan.
- README, panduan instalasi, dan unduhan terbaru diarahkan ke v0.5.1. Berkas v0.5.0 dipertahankan sebagai arsip dan diberi catatan pengganti.

## Yang bisa kamu coba

- Login Google dan perkenalan tiga langkah sampai Bito berpindah ke desktop.
- Chat Qwen lewat layanan demo bersama, dengan pilihan To the point, Chill, Humoris, atau Care.
- Bubble berurutan dengan typing, panel putih yang bisa diubah ukurannya, serta penempatan kiri/kanan mengikuti ruang layar.
- Pengingat, timer, checklist, pembuatan file teks/folder, dan notifikasi bubble di desktop.
- Settings baru, kendali memori, serta penyimpanan lokal yang terpisah per akun.

## Unduhan

- **Mac Apple Silicon:** `Bito-0.5.1-macOS-arm64.dmg` atau `.zip`.
- **Mac Intel:** `Bito-0.5.1-macOS-x64.dmg` atau `.zip`.
- **Windows 64-bit:** `Bito-0.5.1-Windows-x64-Setup.exe`.

[Panduan instalasi](https://github.com/feboyfierlyan/bito-desktop/blob/v0.5.1/docs/INSTALL.md) · [Seluruh fitur checkpoint companion](https://github.com/feboyfierlyan/bito-desktop/blob/v0.5.1/docs/releases/v0.5.0.md)

Repo serta demo tetap privat; akun pengguna harus diizinkan pemilik. Key AI dikelola di server, bukan dimasukkan oleh setiap pengguna.

## Batas pengujian dan distribusi

Mac memakai tanda tangan ad-hoc, **bukan** sertifikat Developer ID atau notarization Apple. Windows belum memakai sertifikat penerbit. Peringatan OS untuk aplikasi demo masih mungkin muncul; ikuti panduan instalasi.

Build native, tes otomatis, checksum, dan verifikasi paket dijalankan sebelum publikasi. Pengujian visual/gesture, login Google, dan percakapan live pada perangkat masing-masing dilakukan pengguna. Pengingat memerlukan Bito berjalan. Kalender, konversi PDF/Office, web search, dan voice belum tersedia.

`SHA256SUMS.txt` dan `BUILD-INFO.txt` menyertai lima installer untuk memeriksa integritas dan asal commit-nya.
