# Mulai memakai Bito

## Download

Buka [rilis terbaru](https://github.com/feboyfierlyan/bito-desktop/releases/latest) dengan akun GitHub yang punya akses repo.

- Mac M1/M2/M3/M4 dan chip Apple yang lebih baru: pilih **macOS-arm64**.
- Mac Intel: pilih **macOS-x64**. Jenis chip terlihat di menu Apple → About This Mac.
- Windows 64-bit: pilih **Windows-x64-Setup.exe**.

## Mac

1. Buka file DMG, lalu seret **Bito** ke **Applications**.
2. Jalankan Bito dari Applications. Jika memilih ZIP, ekstrak dan pindahkan Bito.app ke Applications terlebih dahulu.
3. Paket Mac memakai tanda tangan ad-hoc untuk integritas aplikasi, tetapi belum dinotariskan oleh Apple. Jika macOS menolak aplikasi dari pengembang yang belum dikenali, pastikan file berasal dari repo tim, lalu buka **System Settings → Privacy & Security → Open Anyway** dan ikuti konfirmasi macOS. Jangan menonaktifkan perlindungan sistem secara menyeluruh.

## Windows

1. Jalankan **Bito-0.5.1-Windows-x64-Setup.exe**, lalu ikuti petunjuk instalasi.
2. Installer demo belum memiliki tanda tangan penerbit. Jika SmartScreen muncul, pastikan unduhan berasal dari repo tim sebelum memilih **More info → Run anyway**. Perangkat yang dikelola kampus mungkin memerlukan bantuan administrator.
3. Buka Bito dari shortcut setelah instalasi selesai.

## Kenalan dengan Bito

Masuk dengan Google menggunakan akun demo yang sudah diizinkan. Browser akan terbuka untuk login, lalu kamu kembali ke Bito. Beri nama panggilan, pilih gaya bicara, lalu seret Bito keluar jendela perkenalan ke desktop.

- **Klik:** buka/tutup chat.
- **Seret:** pindahkan Bito; melepas drag tidak membuka chat.
- **Klik kanan:** buka pilihan atau Settings.
- **Ikon tray/menu bar:** tampilkan kembali Bito atau keluar dari aplikasi.

Pengguna tidak perlu menambahkan API key. Jika akses ditolak, hubungi pemilik demo. Jika kuota AI sedang penuh, coba lagi nanti. Pengingat memerlukan Bito tetap berjalan.

## Memperbarui aplikasi

Keluar dari Bito lewat tray/menu bar, lalu pasang versi baru dengan cara yang sama. Jangan hapus data aplikasi jika ingin mempertahankan riwayat. Belum ada pembaruan otomatis; versi sebelumnya tersedia di [semua rilis](https://github.com/feboyfierlyan/bito-desktop/releases).

Data mode revisi terpisah dari aplikasi terpasang. Karena itu, saat pertama membuka installer baru di Mac pengembang, login/onboarding dapat muncul meskipun sebelumnya sudah dicoba di mode revisi.
